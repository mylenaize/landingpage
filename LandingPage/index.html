ReadyToWear

Uma empresa e-commerce fictícia focada em atender clientes com rapidez e qualidade.

A ReadyToWear opera tanto online quanto em lojas físicas distribuídas pelo Brasil. A ideia deste projeto é simular cenários reais de negócios, observando métricas por região e buscando insights que melhorem a experiência do cliente, eficiência operacional e tomada de decisão estratégica.

Minhas Ferramentas de Trabalho

  • Power BI
    • Modelagem & PerformanceEstruturo modelos dimensionais (Star Schema, Snowflake), aplico query folding sempre que possível, otimizo medidas DAX complexas e uso aggregations tables para garantir dashboards rápidos mesmo com grandes volumes de dados.
    • UX & UsabilidadeProjeto layouts e navegação centrados no usuário, aplico hierarquias, tooltips informativos, bookmarks e drill-throughs, garantindo dashboards claros, responsivos e que facilitam decisões rápidas sem sobrecarga cognitiva.
    • Integração & AutomaçãoConecto múltiplas fontes (APIs, web scraping, SQL, Excel), gerencio dataflows, gateways e atualizações incrementais e monitoramento de performance para manter dados sempre atualizados e confiáveis.
  • SQL
    • Consultas performáticasEscrevo queries eficientes usando filtros antes de joins e agregações otimizadas, garantindo extração rápida mesmo com grandes volumes de dados.
    • Preparação de dadosFaço limpeza, padronização e transformação de dados dentro do SQL (normalização, tratamento de nulos e tipos) para que estejam prontos para análise sem sobrecarregar ferramentas de BI.
    • Automação de rotinasCrio views, stored procedures e rotinas agendadas que padronizam processos de extração e transformação, facilitando integração com dashboards e fluxos de análise.
  • Python
    • Data wrangling & tratamento Uso Pandas e NumPy para limpeza, transformação e análise de dados tabulares e bases complexas, aplicando operações vetorizadas para eficiência.
    • Automação & extração Scripts para ingestão de dados via APIs, SharePoint (Office365-REST-Python-Client), web scraping com Requests, BeautifulSoup e Selenium, incluindo logins e interação com formulários.
    • Análise preditiva Desenvolvimento de modelos com Scikit-learn e análises estatísticas com Statsmodels, cuidando de validação cruzada e interpretabilidade (feature importance, métricas) para decisões seguras.
